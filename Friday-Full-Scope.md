# Friday Full Editor Scope

This repository is being validated against the complete Friday Editor Studio scope.

## Scope
- Gutenberg-style block editor behavior
- Paragraph, Heading, List, Quote, Code, Preformatted, Pull Quote, Verse
- Image, Gallery, Cover, Video, Audio, embeds
- Group, Row, Columns, Stack, Slider, Spacer, Separator
- Table and content blocks
- HTML/source mode
- Rich HTML/Markdown/plain-text paste
- Select All, copy/paste, duplicate, delete, undo/redo
- Nested block operations
- Preview/editor consistency
- Responsive desktop/tablet/mobile behavior
- Removal of unwanted Add Block UI
- Runtime/console error prevention
- TypeScript, ESLint and production build validation

## Validation rule
No feature is marked complete merely because code exists. It must be checked against the current implementation and build/CI validation before being called PASS.
